# Lib utilitaires
Vu que je m'embete a réinventer la roue, autant le faire jusqu'au bout.

## tools_string
Fichier avec des fonction utillise pour la gestion des chaines de caracteres.
Elle est tester avec la premiere suite nommé ToolsString.

## tools_tree
Fichier regroupant des fonctions pour utiliser des arbres binaires. 
Il est difficiel (de ma fenetre) de rendre cette classe générique du coup j'ai utilisé les unité lexical afin de mieux gérer la méméoire.
Il y a deux suite de test:  
1. ToolsTree Creation & Destruction : test les partie de création et de déstruction en partant de plusieurs type d'entrée différentes.
2. ToolsTree Others : test tous les autres types de fonctions. Surtout celle d'ajout d'item (pas de suppression pour le moment)
